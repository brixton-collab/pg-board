The Count — how to use it on camera

Tap the big number to add one. That is the whole thing. It is built to be filmed: one number, as large as the screen allows, high contrast, nothing else moving.

Start runs the clock. Undo removes the last tap — use it when someone walks off mid-answer. Reset clears everything for the next take.

Mode cycles: COUNT (a plain tally) → MONEY (adds dollars) → VOTE (two buttons and a live percentage).

Set it up ahead of time with the URL so you never fiddle on camera:

?mode=count&label=YES&target=5&clock=15:00
?mode=money&label=REVENUE&step=5&target=100&clock=30:00
?mode=vote&a=KEEP&b=FIRE

Turn the phone to landscape and the number fills the frame. Turn Do Not Disturb on — a banner ruins the take.
